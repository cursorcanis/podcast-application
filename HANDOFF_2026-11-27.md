breaks when ComfyUI runs on another machine. Now, if the file isn't on disk,
the app downloads it from ComfyUI's `/view` endpoint into the same
`OUTPUT_FOLDER` path.
- `app/comfyui.py`: new `download_output()`
- `app/render.py`: new `_fetch_output_file()`, used in the worker loop. If the
  download fails, the chunk is marked failed and retried.
- `app/settings.py`: the voice-profile sample render uses the same helper.
- `tests/test_render.py`: two new tests (local file present; remote
  download). **Both pass.**

## 3. How to restart the pipeline

1. On alea-nvidia, if ComfyUI isn't up:
   `ssh alea-nvidia "schtasks /Run /TN PodcastFoundryComfyUI"`
   To check it: `ssh alea-nvidia "curl.exe -s http://127.0.0.1:8189/system_stats"`
2. Tunnel (from WSL; Windows sees it through localhost forwarding):
   `ssh -N -o ServerAliveInterval=30 -L 127.0.0.1:8191:127.0.0.1:8189 alea-nvidia`
3. App: `start_app.bat`, or
   `.venv-win\Scripts\python.exe -m uvicorn app:app --host 127.0.0.1 --port 8010`
   The 2026-11-26 run logged to `data/app_server_2026-11-26.log`.
4. The Status page (`/`) should show ComfyUI reachable at 127.0.0.1:8191.

Yesterday the tunnel and the app ran inside the Claude Code session. If that
session closed, both are down and need steps 2–3.
